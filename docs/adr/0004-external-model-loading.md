# ADR 0004: External model loading with fallback

- Status: accepted
- Date: 2026-09-22

## Context

比較用の500 mLペットボトルは、単純な円柱だけでは実物感が弱い。一方、脂肪の公開3Dモデルは出所・ライセンス・形状の正確性を確認できないまま採用すると、仕様と権利の両方で問題になる。

## Decision

比較ボトルは、ワークスペースに提供された `pet-bottle-500ml.glb` をGLTFLoaderで読み込む。読み込みに失敗した場合は、Three.js生成ボトルを表示する。脂肪は、ワークスペースに提供された `adipose-10g.glb` と `adipose-100g.glb` をGLTFLoaderで読み込み、サイズと原点を正規化して使用する。表示量が100g未満の場合は10gモデル、100g以上の場合は100gモデルを選び、基準重量から立方根スケールする。読み込みに失敗した場合は、生成した単一メッシュを表示する。

3Dビューにはホイールと `+ / - / 1:1` ボタンによるズームを追加する。ズームはカメラに適用し、脂肪と固定比較物を同じ倍率で表示する。現在倍率もビュー上に表示する。

## Consequences

- 外部モデル表示にはネットワーク接続が必要
- 外部モデルの取得不能時も画面は利用できる
- 脂肪モデルは現在の単一メッシュを保持し、将来GLBへ差し替えられる構造になる
- `WaterBottle.glb` の配布条件は利用前に確認する
