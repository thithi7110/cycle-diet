# ADR 0002: Reference-model fat mass

- Status: accepted
- Date: 2026-09-22

## Context

最初のCSS 3D表現は、複数の球体と上下の楕円を組み合わせた抽象形状だった。これは脂肪細胞の説明図としても、添付された1 kgの脂肪模型としても不正確で、回転すると薄い部品の集合に見える。

## Decision

脂肪モデルは、添付画像の脂肪模型を外観基準にする。横長で低く、押しつぶされた不定形の一塊として造形し、表面には独立した球ではなく連続した細かな隆起とくぼみを持たせる。色は淡いクリーム色から薄い黄み、材質は湿った柔らかな半光沢とする。

3D表現では、正面・側面・背面のどの角度でも同じ塊の連続したシルエットが見えることを優先する。量の変化は球の追加ではなく、同一メッシュのスケール変化で表現する。

## Consequences

- 現在のCSSの球体小葉と上下の楕円パーツは置き換え対象になる
- CSS 3Dだけで十分な表面の不規則さや厚みを表現できない場合は、単一メッシュのWebGL/Three.jsモデルへ移行する
- 医学的な組織構造を再現するのではなく、重量感と見た目の認識を優先する
- 仕様レビューでは正面だけでなく、ドラッグ回転した斜め・背面も確認する
