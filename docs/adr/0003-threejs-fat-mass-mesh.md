# ADR 0003: Three.js single-mesh fat mass

- Status: accepted
- Date: 2026-09-22

## Context

CSS 3Dでは、脂肪の塊を回転したときの連続した側面、薄い厚み、細かな不規則な表面を安定して表現できない。独立した小葉や疑似的な上下パーツに分解すると、実物の脂肪模型ではなく部品の集合に見える。

## Decision

Three.jsで単一の変形球メッシュを生成する。基礎形状を横長・低い楕円体にし、頂点位置を低振幅の複合ノイズで変形して、連続した不規則な脂肪塊を作る。`MeshPhysicalMaterial` の淡いクリーム色、粗さ、弱いクリアコートと、柔らかな複数光源を使う。

モデルの回転は既存のポインタードラッグ操作で行い、量の変化はメッシュ全体のスケールで表現する。外部の3Dアセットは使わず、形状の再現性を保つためコードで生成する。

## Consequences

- Three.jsをCDNから読み込むため、ローカル表示時もネットワーク接続が必要になる
- GPU/WebGLが必要になる
- 形状、材質、照明を個別に調整でき、回転時も一塊として見える
- 将来的に実物スキャンや高精度メッシュへ差し替える場合も、シーンとデータ表示を分離できる
