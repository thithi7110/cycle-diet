# ADR 0001: Browser-first visualization

- Status: accepted
- Date: 2026-09-22

## Context

最初に検証したいのは、DC1のデータ連携よりも、ペダリング量が脂肪の形として見える体験と、日々の記録を振り返る導線である。プロジェクトは空の状態で、外部依存やビルド環境を先に増やす必要はない。

## Decision

MVPは単一の `index.html` とし、CSSとJavaScriptを同居させる。3DはWebGL導入前の検証としてCSS 3Dで表現し、ポインタードラッグで回転できるようにする。データはブラウザ内のデモ状態から始める。

## Consequences

- ローカルファイルを開くだけでレビューできる
- 体験検証が速い
- 本格的な3D形状、永続化、DC1連携は後続の境界変更が必要になる
- 脂肪量の数値は可視化用換算値として明示する
