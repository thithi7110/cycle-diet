# Product Specification

## Goal

CYCPLUS DC1のペダリング量を、継続の実感につながる形で見える化する。ユーザーは「今日どれだけ消費したか」と「積み重ねでどれだけ変化したか」を同じ画面で確認できる。

## MVP scope

- 今日の消費カロリーと脂肪換算量を表示する
- 本日の消費カロリーと本日の脂肪換算量を同じ換算式で連動表示する
- 累積の脂肪換算量を表示する
- DC1から受信した速度をダッシュボード形式で表示する
- 今日／累積の3Dモデル表示を切り替える
- 3Dモデルをポインタードラッグで回転する
- 3Dモデルをホイールまたは画面上のボタンで拡大縮小する
- 日付カレンダーから記録日を選択する
- カロリーを手動入力してその日の記録に追加する
- 最近のアクティビティを表示する

## Interaction

- カレンダーの日付を選ぶと、その日のカロリー、脂肪換算量、ログ件数が画面に反映される
- 3Dモデルはドラッグ中に回転し、離しても最後の向きを保持する
- 今日／累積の切替では、同じモデル表現を対象データに合わせて更新する

## Fat mass visual specification

添付の「脂肪模型 1 kg」画像を見た目の基準とする。表示するものは脂肪細胞の拡大模型ではなく、実物の脂肪組織をまとまりとして見たときの一塊である。

### Shape

- 基本形は、横に広がった低い塊。球体、円柱、ボール、肉まんのような形にはしない
- 外周は左右対称にせず、押しつぶされた不定形の輪郭にする
- 厚みはあるが、幅・奥行きに対して明確に薄い。回転すると側面と裏面が見える
- 表面は細かな脂肪組織の隆起と浅いくぼみが連続する。独立した球が並んで見える表現は禁止
- 上下に意味のない楕円プレート、輪、台座、キャップを置かない

### Material and surface

- 色は白に近い淡いクリーム色から薄い黄み。オレンジ色の果肉のようにしない
- 表面は湿った脂肪組織らしい、柔らかい半光沢。金属、陶器、ゼリー、プラスチックには見せない
- ハイライトは細く不規則に連続し、表面の細かな凹凸を拾う
- 内部の球形パターンや血管・筋繊維など、根拠のない細部は追加しない

### 3D and scale behavior

- 正面では添付画像のような薄い塊に見え、回転時は厚みのある側面が連続して見える
- 180度回転しても、平面スプライトや紙片のように見えない
- 形状の向きはドラッグ方向に自然に追従し、急な反転や上下の固定パーツの分離を起こさない
- 表示量が増えると塊の体積が増える。別の球を追加するのではなく、同じ塊が大きくなる
- モデルの横に500 mLペットボトル相当（約21 cm）の簡易スケールを置き、絶対的な大きさを比較できる
- 比較用ボトルは脂肪モデルとは独立した固定位置の立体モデルとする
- `adipose-10g.glb` と `adipose-100g.glb` を脂肪量の基準モデルとして使用し、表示量に近いモデルを選択して立方根スケールする
- `pet-bottle-500ml.glb` を500mLの固定比較モデルとして使用する
- 脂肪密度を約0.9 g/mLとして体積を換算する。13.3 gは約15 mLであり、1 kg相当の大きさでは表示しない
- 表示サイズは脂肪量に対して体積比で変化させるため、線寸法は脂肪量の立方根に比例させる
- 500 mLペットボトルと13.3 gの脂肪塊は、体積比約3%（15 mL / 500 mL）として見えること。線寸法が同じ比率になる必要はないが、脂肪塊がボトルの大部分に見えてはならない
- 脂肪量は1g単位で実績を表示する。1gを日次目標にはせず、カロリー目標とは別の実績単位として扱う

### Acceptance checks

- 3秒見ただけで「脂肪の塊」と認識できる
- 球体が7個並んでいるように見えない
- 上下の楕円パーツが存在しない
- 正面、斜め、背面の3方向で同じ一塊として成立する
- 添付画像の色、薄さ、表面の不規則さから大きく外れない

## Data model (demo)

```text
DayLog {
  date: YYYY-MM-DD
  calories: number
  entries: [{ time: HH:mm, calories: number }]
}
```

## Out of scope

- DC1本体とのBluetooth接続
- 医療目的の体脂肪測定
- ユーザー認証、クラウド同期、複数ユーザー
